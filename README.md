# 🎵 Amazon Music Clustering

Unsupervised machine-learning project that groups Amazon Music songs into clusters using only their **audio characteristics** (no genre labels). The clusters can be used for playlist generation, song recommendation, and listener segmentation.

---

## 1. Problem statement
With millions of songs on Amazon Music, manual genre tagging is impossible. Goal: automatically group similar songs based on audio features such as `danceability`, `energy`, `tempo`, etc., using clustering.

## 2. Dataset
`single_genre_artists.csv` — **95,838 songs**, 23 columns.

| Type | Columns |
|---|---|
| Identifiers (dropped) | `id_songs`, `id_artists`, `name_song`, `name_artists`, `genres`, `release_date` |
| Audio features (used) | `danceability`, `energy`, `loudness`, `speechiness`, `acousticness`, `instrumentalness`, `liveness`, `valence`, `tempo`, `duration_ms` |

## 3. Approach
1. **EDA & cleaning** — drop nulls/duplicates, drop ID/text columns
2. **Scaling** — `StandardScaler` (clustering is distance-based)
3. **Find optimal k** — Elbow method + Silhouette score
4. **Clustering** — KMeans (final), DBSCAN, Hierarchical (compared)
5. **Evaluation** — Silhouette, Davies-Bouldin, Calinski-Harabasz
6. **Dimensionality reduction** — PCA (2 components) for visualisation
7. **Profiling** — mean feature value per cluster → human label (e.g. *"High-energy danceable / Party"*)
8. **Export** — labelled CSV + cluster profile + Streamlit app

## 5. How to run
```bash
# 1. install dependencies
pip install -r requirements.txt

# 2. run the full pipeline (writes outputs/ folder + plots)
python clustering.py

# 3. launch the dashboard
streamlit run app.py
```

## 6. Results
- KMeans typically chooses **k = 4–6** based on silhouette
- Cluster profiles map cleanly to mood labels: *Party*, *Chill / Acoustic*, *Instrumental*, *Speech / Hip-hop*, *Mainstream*
- The PCA scatter shows visible separation between clusters

## 7. Business use cases
| Use case | How clusters help |
|---|---|
| Personalised playlists | Group sonically similar songs into auto-playlists |
| Recommendation | Suggest tracks from the same cluster as a user's favourites |
| Artist analytics | Show artists who they sonically compete with |
| Market segmentation | Cluster listening data for promotions |
